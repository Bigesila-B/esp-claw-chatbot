## 与官方版本的差异

定制版发布在 `feature/context-compaction`，固件基于官方 [`a4edfe5`](https://github.com/espressif/esp-claw/commit/a4edfe594a99407c8b4d5d70b93906bdd762b745)。官方已有 Skills、Lua、QQ 机器人、MCP 和模型图片输入，表中列的是本分支在这些能力上的改动。

| 功能 | 官方基线 | 定制版 |
| --- | --- | --- |
| 增强功能入口 | Web 侧栏提供设备设置和聊天 | 「增强功能」集中提供 MCP 设置、技能、指令、图片聊天和会话设置。 |
| 聊天帮助 | 各条指令有自己的帮助入口 | Web 新增「指令列表」，聊天可发 `/help`。两处展示可用的聊天指令、中文说明、日期、CPU 和内存使用情况、今日及本月 token 用量和局域网 IP。聊天中的 `/help` 还显示当前会话的上下文用量。模型连接在网页「模型设置」中管理。 |
| 回复提示 | 默认路由会发送「🦞 ESP-Claw is snapping on it...」，工具过程通知由构建配置控制 | 新装使用的规则已移除固定提示。Web 可随时切换工具调用过程通知，默认关闭。 |
| MCP | 已有 MCP Client 和 Server 能力 | Web 的「MCP 设置」可保存最多四个命名服务，并逐个测试连接。适配的生图任务完成后会自动发回原聊天。 |
| Skills | 已有 Skills 和 Lua 脚本 | Web「技能列表」可直接上传 Skill，并显示已加载的 Skills 和不可用的依赖工具组。带 PSRAM 的 ESP32-S3 可选用 MicroPython 运行小型 Python 脚本。 |
| 网页图片 | 单文件上传接口上限为 512 KiB | 在线聊天和文件管理会在浏览器里压缩超限图片。优先保留尺寸和细节，传给设备的文件仍在上限以内。 |
| 收图缓存 | 入站附件保存在设备的 inbox 中 | QQ、Telegram、飞书、微信和网页聊天共享 1 MiB 图片缓存。空间不足时清理最旧的图片副本，传输失败时清理临时文件。 |
| 图床表情包 | 各聊天通道提供图片发送能力 | `/sticker` 在设备上查目录并发送表情。设备只处理链接，查询无需聊天模型。 |
| 云端图片与语音 | 各聊天通道提供收发附件能力 | 普通 HTTP 生图、语音合成和转写模型可在 Web 后台配置。聊天中创建的生图草稿会出现在模型列表。 |
| 缓存统计和提醒 | 有模型调用和设备调度能力 | 显示模型报告的输入缓存命中率，并在 Web 管理一次性、间隔和每日提醒。 |
| 网页加载 | 由设备发送固件内嵌的压缩网页 | 完整发送 gzip 资源，避免压缩文件末尾的字节被误删后导致网页加载失败。 |
| 会话记忆 | 会话文件达到大小阈值后压缩 | 增加「上下文窗口 (token)」设置和基于模型窗口的压缩阈值。压缩时优先保留最近的对话，并尝试生成较早内容的摘要。 |
| 聊天恢复 | 模型失败时可能显示内部错误码 | 超时、限流和空间不足会显示中文提示。发送 `/retry` 可取回当前会话的上一条已保存回答，或重试上一条文字问题。 |
| 存储写满 | 会话索引重建失败可中断本轮回复 | 在无法读取历史且索引重建失败时，尽量继续生成本轮回复。上传明确报告存储不足，释放空间后可恢复因写满中断的 Skill 激活。 |

定制版已合入官方 Web 会话历史。刷新网页可恢复设备上已保存的聊天记录，在侧栏切换会话并分页查看较早的消息。[上游实现](https://github.com/espressif/esp-claw/commit/9354591b845371904d043dd4f7258e5f6ee69f61)

## 使用方法

### 新增聊天指令

| 指令 | 用途 |
|------|------|
| `/help` | 列出指令并显示日期、局域网 IP、CPU、内存、token 用量和当前会话的上下文估算 |
| `/retry` | 从当前会话重发已保存的答案，或在上一轮失败时重试文字问题 |
| `/sticker [名称]` | 查看图床表情包目录，或按名称发送一张表情 |
| `/image <描述>` | 用已启用的云端生图模型生成图片 |
| `/tts <文字>` | 用已启用的云端语音模型朗读 |
| `/mcp models [起始位置]` | 查询默认 MCP 服务公开的模型目录。支持分页的目录可从指定位置继续 |
| `/mcp last-image` | 在原聊天重发近期 MCP 生图结果 |

上游的 `/session` 指令菜单及回复已经中文化。

- **指令和用量**。打开「增强功能 → 指令列表」，或在聊天里发 `/help`。Web 聊天用设备图标显示帮助标题。设备直接处理帮助命令，免用模型 token。`/help` 根据当前会话的历史和摘要估算上下文 token 数，并显示窗口上限和占用比例。今日和本月的用量以模型 API 返回的用量为准，按设备时区累计，从启用后开始记录。局域网设置页可通过显示的 IP 打开。
- **旧设备关闭固定提示**。升级会保留已有路由。若仍看到小龙虾提示，在设备串口控制台运行 `auto rules`，确认规则存在后运行 `auto delete_rule im_any_message_working_reply`。
- **显示或隐藏工具调用过程**。在「增强功能」切换「显示工具调用过程」，点「保存本页」。保存后即时生效，工具本身仍可被模型调用。
- **连接 MCP**。在「增强功能 → MCP 设置」为每项服务命名，填入它的 Streamable HTTP 或旧版 HTTP＋SSE 地址和可选的 Bearer Token，逐个测试后保存。在「Capabilities 管理」中为 LLM 启用 MCP Client 并重启后，就能在聊天中按服务名称调用工具。发图按所选服务提供的工具和返回字段执行。
- **查看和使用 Skills**。打开「增强功能 → 技能列表」。看到 `cap_micropython` 时，可在「在线聊天」发送「请用 cap_micropython 运行内置示例，把 count 设为 7 并返回结果」，示例的 sum 为 28。
- **上传自定义 Skill**。在「技能列表」点「上传 Skill」，选择含 `SKILL.md` 的文件夹，或直接选择独立的 `SKILL.md`。设备用 ESP-Claw 的 JSON 格式校验技能，将文件保存到 `/skills/<name>/` 并保留子目录。上传后点击「重启生效」。同名目录受保护，原有技能文件会保留。
- **安装 Python Skill**。构建时在 `idf.py menuconfig` 打开 `App Claw Config → App Claw Capabilities → Enable MicroPython scripts for Skills`。在 Skill 的 `SKILL.md` 声明 `cap_micropython` 工具组，通过 `python_run_script` 运行 `{CUR_SKILL_DIR}/scripts/...`，用 `args` 接收 JSON 参数，用 `print()` 返回结果。
- **发送大图**。在 Web 聊天选图，压缩完成后发送。512 KiB 及以内的原样上传。超限图片先尝试保留原始尺寸，必要时降低 JPEG 质量或缩小图片。透明 PNG 若转成 JPEG 会用白底，压缩的动图只保留一帧。识图模型须支持设备上传的图片。
- **发送图床表情包**。发送 `/sticker` 查看目录，发送 `/sticker 笑哭` 选一张。Web、QQ 和 Telegram 发图，飞书和微信回图片链接。可在「文件管理」根目录上传 UTF-8 的 `stickers.txt` 替换默认目录，每行填写 `名称=https://图床地址/图片.png`，文件最多 16 KiB。命令每次读取目录，上传后即可使用。默认图片来自 [Twemoji](https://github.com/jdecked/twemoji)，由 Twitter, Inc. 和贡献者创作，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。
- **按语境自动发表情**。Web、QQ 和 Telegram 的普通聊天可以随正文附上至多一张贴合语境的表情。模型在同一次回复里从目录的前 12 个可用名称中挑选。「增强功能」可开关功能并把发送频率调到 0–100%，默认 50%。频率只作用于模型选中表情的回复，保存即生效。
- **配置云端媒体**。打开「LLM 设置 → 云端图片与语音模型」。在聊天中提供生图或语音合成的接口地址、模型 ID 和接口文档，可让机器人创建草稿，再到 Web 填写密钥并启用。生图和通用语音接口可以返回媒体 URL，生图也可按任务 ID 轮询同一服务。添加语音合成模型时可选择小米 MiMo TTS 预设。设备解码 MiMo 返回的 MP3 或 WAV 后发往 QQ 或 Telegram，Web 聊天保留最近三段生成的语音供播放。每段解码音频上限为 128 KiB。语音转写以分块方式上传音频，Web 单个音频上传上限为 512 KiB。
- **通过聊天配置语音合成**。在机器人私聊或设备 Web 聊天按行发送 `URL: 接口地址`、`Key: 接口密钥` 和 `Model ID: 模型 ID`。设备试合成成功后会保存为默认语音合成模型。
- **自动发送语音回复**。在「云端图片与语音模型」编辑语音合成模型，可选填服务商的音色 ID。选择「关闭」「文字和语音」或「仅语音」，档位保存后立即生效。QQ、Telegram 和 Web 聊天使用第一个已启用的语音模型，合成或发送失败时保留文字。Web 双发的音频在实时聊天中播放。Web 仅语音的本地音频缓存过期后，可在历史记录里读到原文。
- **查看缓存和设置提醒**。`/help` 显示有数据的本月输入缓存命中率，Web「指令列表」显示今日和本月数据。页面下方的「定时提醒」可选择聊天并设置一次性、间隔或每日提醒。
- **调整上下文窗口**。在「增强功能」填写模型的上下文窗口，保存后重启设备。使用 0 或留空可按模型名自动匹配。设备约在窗口的 60% 启动压缩，另有约 150 KiB 的会话文件阈值兜底。可用 `/session new` 新建会话，`/session list` 查看会话。

## ESP32-S3 实测范围

已用 16 MiB Flash、8 MiB PSRAM 的 ESP32-S3 验证帮助、token 计数、MCP 工具调用、自定义 Python Skill、网页大图上传、Skill 文件夹上传和存储写满后的聊天回复。图片缓存通过本地的容量、空间不足、正在读取的文件、重复传输和中断清理测试。

最新 ESP32-S3 测试的应用镜像大小为 3,041,056 字节，在 3,800 KiB 应用分区剩约 830 KiB。已在板上验证表情频率能保存 0% 和 100%。云端生图与语音合成使用局域网模拟接口联测，语音转写通过本地模拟测试。不同板型以构建输出和实际分区表为准。

MicroPython 是按需启用的嵌入式运行时，测试配置分配 256 KiB PSRAM 堆，支持部分内置模块和脚本目录内的导入。脚本单文件上限为 32 KiB，默认超时 1 秒，最大 5 秒，最多捕获 4,095 字节的输出。依赖桌面 Python 第三方库或系统命令的 Skills 需要适配，外设和网络操作可使用已有的 Lua 模块与工具。

存储写满时，新消息可能无法保存到历史。若 QQ 收到 `ESP_FAIL`，可先在「文件管理」检查是否有占用较大的附件。复用已有的 `sdkconfig` 构建时，将 `CONFIG_FATFS_FS_LOCK` 设为 32，使图片缓存清理能够跳过打开的文件。上下文摘要的长会话效果仍需持续验证。
